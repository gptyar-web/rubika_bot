# آزمون و حدود اعتبارسنجی

بررسی در ۱۵ اکتبر ۲۰۲۶، با Node.js 24 انجام شده است. این گزارش، اجرای محلی و شبیه‌سازی‌شده را از اجرای مرورگر و اتصال زنده جدا می‌کند.

## نتیجهٔ آزمون‌های اجراشده

`npm test`: **۲۰ آزمون موفق، صفر شکست**. شمار آزمون‌ها به معنی تأیید مستقل هر یک از ۱۵۰ قابلیت نیست؛ بخش‌های پوشش‌داده‌شده در زیر آمده‌اند.

- **رمزگذاری:** رفت‌وبرگشت AES-GCM، IV تازه در هر ذخیره، نبود توکن خام در envelope، رد رمز نادرست، رد ciphertext دست‌کاری‌شده و پارامتر ضعیف KDF.
- **ذخیره‌سازی IndexedDB شبیه‌سازی‌شده:** ساخت، ذخیره، خواندن مجدد، پشتیبان، تغییر رمز، قفل، بازیابی و رد revision قدیمی زبانهٔ دیگر.
- **Adapter API با پاسخ شبیه‌سازی‌شده:** تلاش مجدد خواندن، تکرارنکردن ارسال نامشخص، رد پاسخ نامعتبر یا ناموفق، مقصد رسمی ثابت و الزام HTTPS/کلید برای واسط.
- **دادهٔ پیام:** متن، نظرسنجی، مختصات و پاسخ با شناسهٔ پیام؛ رد دادهٔ ناقص.
- **قوانین:** استثناهای مدیر، دامنهٔ مجاز و دامنهٔ مشابه مخرب، محدودهٔ شمارندهٔ ضداسپم، نرمال‌سازی فارسی، رد الگوهای خطرناک و ساعات تهران.
- **رویداد و صف:** جلوگیری از پاسخ دوباره، نادیده‌گرفتن مقصد ناشناخته و پیام خود بات، تکرارنکردن مقصد موفق، توقف پست قدیمی، ثبت نتیجهٔ نامشخص، فرم متنی چندمرحله‌ای و تیکت با دستور صریح.
- **فرم‌ها در Happy DOM:** ثبت و اعتبارسنجی بات، رد توکن تکراری، مقصد مجاز، ارسال موفق و ناموفق، قانون، قالب/کیبورد، رد دکمهٔ تکراری، پیش‌نویس، رد محتوای تکراری، تأیید زمان تهران، تیکت و تنظیمات.
- **رندر DOM:** وجود صفحهٔ اصلی هر مسیر، جدول دقیقاً ۱۵۰ ردیفی و escapeشدن مقدارهای HTML مخرب در صفحه‌ها.
- **خروجی:** خنثی‌کردن آغازگر فرمول در CSV و جایگزینی محدود متغیرهای قالب بدون اجرای کد.

`npm run check`: بررسی نحو JavaScript، نبود تداخل گیت، CSP بدون کد inline، فایل واقعی فونت و آیکون، مسیرهای نسبی PWA و یکتایی ۱۵۰ شناسه.

`npm run build`: ساخت موفق خروجی ایستا با فهرست مجاز. فایل‌های نشست، دادهٔ قدیمی، کد پایتون و تست‌ها در `dist` قرار نمی‌گیرند.

## آزمون مرورگر واقعی: اجرا نشده

سناریوی `tests/browser.mjs` با Playwright نوشته شده و در GitHub Actions پیش از انتشار اجرا می‌شود. سناریو شامل ذخیرهٔ توکن پس از reload، رمز اشتباه، دو زبانه، همهٔ مسیرها در عرض‌های ۳۹۰، ۷۶۸ و ۱۴۴۰، گردش‌کار پیام/قالب/صف و API شبیه‌سازی‌شده است.

در محیط این گفتگو اجرای Chromium با `SIGTRAP` پایان یافت؛ مرورگر ابری نیز به سرور محلی با `ERR_CONNECTION_REFUSED` دسترسی نداشت. بنابراین **بازبینی بصری، رفتار واقعی موبایل، صحت کنتراست، نصب PWA و عملکرد آفلاین در مرورگر تأیید نشده‌اند**. هیچ تصویری از صفحه به‌عنوان مدرک آزمون موفق ارائه نمی‌شود. آزمون DOM جایگزین تضمین رفتار مرورگر نیست.

برای اجرای مستقل:

```sh
npm ci
npx playwright install --with-deps chromium
npm run test:browser
```

در محیط دارای Chromium از پیش نصب‌شده می‌توان `BROWSER_EXECUTABLE` را به مسیر آن تنظیم کرد. خروجی تصویری آزمون، در صورت اجرای موفق، داخل `test-results` قرار می‌گیرد و در مخزن ثبت نمی‌شود.

## اتصال واقعی روبیکا: اجرا نشده

توکن واقعی در اختیار آزمون قرار نگرفته است. اعتبار توکن، CORS سرور روبیکا، دسترسی بات در گروه/کانال، ارسال واقعی، حذف و مسدودسازی زنده آزمایش نشده‌اند. همهٔ درخواست‌های آزمون به پاسخ شبیه‌سازی‌شده متصل‌اند. کلیدها و شناسه‌های تست ساختگی‌اند.

واسط JavaScript ارائه شده، روی سرویس خارجی مستقر نشده است. این نسخه ادعای تضمین امنیت production، آزمون نفوذ، ممیزی رمزنگاری مستقل، Webhook دائمی یا تأیید اجرایی کد پایتون قدیمی ندارد.
